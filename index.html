Operating rules

Four rules that stop agents from lying to you.

01

Receipts, not reports

Every claim an agent makes links to the run that produced it: inputs, code path, outputs, hash.

02

No self-grading

The agent that did the work never approves it. An independent validator checks against a contract.

03

Frozen source of truth

A known-good snapshot to fall back to. When things break, retrace from it — then go forward.

04

Drift is measured

Compare each handoff to the original intent. Drift becomes a number, not a vibe.
