01 — The problem

You cannot trust an agent that writes its own test.

Every enterprise running AI agents hits the same wall: the agent says it did the work, but nobody can prove it — or disprove it. The evidence is in the agent's output, and the agent is the one grading it. Guardrails and logging do not solve this; they help after the fact, but they cannot show that what happened actually matched what was supposed to happen.

What Agent Notary changes

The agent does not grade itself. A separate, independent implementation recomputes the artifact and agrees or refuses. The receipt is stored in an immutable Merkle DAG. If the two implementations disagree, the artifact does not advance — by design, not by exception.

02 — The protocol

Notarized actions, not intentions.

Agent Notary does not watch agents. It witnesses them — cryptographically — and refuses to let a claim stand without evidence.

1 · Witness

Every agent action passes an independent implementation (Zig) that recomputes the artifact. Two codebases must agree before anything advances.

2 · Notary

A sealed, Ed25519-signed receipt is issued for every witnessed action — stored in a WORM SQLite blackboard with attribution, Merkle root, and timestamp.

3 · Recover

If verification fails, the action does not advance. Quarantine-not-delete: the broken state is preserved for forensic review, never discarded silently.

4 · Prove

Every artifact carries a dual-implementation proof that any third party can independently verify — no trust required, no proprietary black box.
